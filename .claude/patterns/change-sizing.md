# Change Sizing

Shared sizing heuristic used by `/implement` and `/review`.

| Size | File Impact | Keywords | `/review` Profile |
|------|-------------|----------|--------------------|
| **Trivial** | 1 file, <10 lines | typo, rename, comment | `trivial` |
| **Small** | 1–2 files, <50 lines | bug, fix, update | `small` |
| **Medium** | 3–5 files, design choices | endpoint, route, service, refactor | `medium` |
| **Large** | 5+ files, architectural | new service, new integration, new background worker, migration | `full` |
